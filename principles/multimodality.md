# Multimodality

Multimodality means interaction across input and output paths such as touch, keyboard, voice, gaze, gesture, haptics, captions, screen readers, and spatial movement.

More modalities do not automatically mean more access. Each modality carries assumptions, constraints, and failure modes.

## Guidance

- Treat modalities as equivalent paths where possible, not novelty layers.
- Distinguish input modalities from output modalities.
- Include assistive technologies in the modality model.
- Avoid making one signal the only source of truth.
- Consider environmental constraints such as glare, noise, motion, crowding, and low connectivity.

## Useful Questions

- What can the user perceive?
- What can the user control?
- What happens when a modality is unavailable?
- Are critical signals redundant across modalities?
- Does the system preserve meaning when switching devices?
- Does multimodal adaptation preserve predictability?
